# Day 11 ? Logging and Exception Hardening

## Learning

- [x] Request logging, structured context, log levels, SLF4J, Logback, and MDC.
- [x] Exception hierarchy design, unchecked exceptions, and polymorphic `@ExceptionHandler` handling.

## Implementation

- [x] Add `RequestLoggingFilter` with method, path, status, duration, request ID, and response header propagation.
- [x] Configure logging through `logback-spring.xml`.
- [x] Establish the shared base-exception hierarchy and catalog-specific exceptions.
- [x] Extend `GlobalExceptionHandler` for framework and business exceptions.
- [x] Fix invalid sort handling and product-status transition defects.
- [x] Add a dedicated test environment and HTTP test suite.

## Outcome

- [x] Requests are logged with useful context without logging sensitive bodies or headers.
- [x] Errors have consistent codes and safe responses; unexpected 500 responses were investigated and fixed.
